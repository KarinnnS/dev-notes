# SQL — шпаргалка

Мои заметки по SQL и PostgreSQL.

Здесь собраны основные команды, их объяснения и примеры использования.

## SELECT — выборка данных

**Назначение:** получение данных из таблицы.

**Синтаксис:**
```sql
SELECT column1, column2
FROM table_name;
```

**Пример:**
```sql
SELECT name, age
FROM employees;
```

**Примечания:**
- `SELECT *` — выбрать все столбцы.
- `SELECT column1, column2` — выбрать только указанные столбцы.
- `FROM` — указывает источник данных.

## WHERE — фильтрация данных

Используется для отбора строк, соответствующих заданному условию.

**Синтаксис:**

```sql
SELECT column1, column2
FROM table_name
WHERE condition;
```

Пример:

```sql
SELECT name, age
FROM employees
WHERE salary < 5000;
```

Выводит имена и возраст сотрудников, у которых зарплата меньше 5000.

Операторы сравнения:

| Оператор | Значение |
|---|---|
| `=` | Равно |
| `<>` или `!=` | Не равно |
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |

## Логические операторы

| Оператор | Значение |
|---|---|
| `AND` | Все условия должны выполняться |
| `OR` | Достаточно выполнения хотя бы одного условия |
| `NOT` | Отрицание условия |

Несколько условий:

```sql
SELECT *
FROM employees
WHERE age > 25 AND salary < 5000;
```
